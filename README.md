# GoPoints

Android-приложение для водителя-экспедитора: весь день следит за местоположением,
по кнопке «Отметить» запоминает точку, а в конце дня выдаёт список мест,
где ты был, со временем на каждой точке.

## Скачать

Каждый пуш в `main` собирается в GitHub Actions. Готовый APK лежит в
[Releases](../../releases/latest): откройте страницу с телефона, скачайте
`GoPoints-N.apk` и установите поверх прежней версии (данные сохраняются).

## Что умеет (этап 1–2)

- **Смена:** таймер отработанного времени, пробег по GPS.
- **Отметка точки:** кнопкой в приложении, кнопкой «Отметить» в уведомлении
  или двойным нажатием «громкость вниз» (работает и при выключенном экране
  на большинстве прошивок).
- **Автоотметка:** простоял на месте 5 минут, а точки нет — спросит
  «отметить?», без ответа отметит сам.
- **Время на точке:** от отметки до момента, когда отъехал дальше 80 м.
  Несколько магазинов на одном адресе закрываются вместе.
- **Адрес** определяется сам («ул. Ленина, 145»), к отметке можно
  надиктовать голосовую заметку.
- **Отчёт дня** текстом в любой мессенджер.
- **Календарь** с часами по дням и **статистика** (столбцы, линия, область).

Дальше по плану: маршрут с голосовым вводом адресов и передачей в
Яндекс Навигатор, фото накладных, топливо.

## Сборка

```
./gradlew assembleDebug
```

Kotlin, Jetpack Compose, Fused Location. Данные — JSON-файлы по дням
в памяти телефона, никуда не отправляются.
