# GoPoints

Android-приложение для водителя-экспедитора: весь день следит за местоположением,
по кнопке «Отметить» запоминает точку, а в конце дня выдаёт список мест,
где ты был, со временем на каждой точке.

## Скачать

Каждый пуш в `main` собирается в GitHub Actions. Готовый APK лежит в
[Releases](../../releases/latest): откройте страницу с телефона, скачайте
`GoPoints-N.apk` и установите поверх прежней версии (данные сохраняются).

## Что умеет (этапы 1–3)

- **Смены:** таймер, пробег по GPS; несколько смен за день считаются отдельно.
- **Отметка точки:** кнопкой в приложении, кнопкой «Отметить» в уведомлении
  двойным нажатием «громкость вниз» (и при выключенном экране) или кнопкой
  гарнитуры.
- **Автоотметка:** простоял на месте 5 минут, а точки нет — спросит
  «отметить?», без ответа отметит сам.
- **Время на точке:** от отметки до момента, когда отъехал дальше 80 м.
  Несколько магазинов на одном адресе закрываются вместе.
- **Адрес** определяется сам («ул. Ленина, 145»), к отметке можно
  надиктовать голосовую заметку.
- **Отчёт дня** текстом в любой мессенджер.
- **Календарь** с часами по дням и **статистика**: часы, точки, простой,
  пробег (столбцы / линия / область), средние показатели.

- **Маршрут:** точки голосом или вручную (Благовещенск, сёла вокруг и города
  области: «Марково, Центральная 5») → адреса находятся на карте →
  порядок объезда (ближайший сосед + 2-opt, окна приёмки «до 12:00»
  учитываются) → «Открыть в Навигаторе». Несколько магазинов на одном адресе
  — одна остановка. Любую точку можно «Начать с неё» или «Отложить» в конец.
  Точка считается сделанной, когда рядом стоит отметка.
- **Диктовка адресов:** называешь адреса подряд — каждый становится строкой
  и сразу проверяется по карте (✓ / ⚠ исправить). Несколько адресов в одной
  фразе режутся по номерам домов. «Добавить» — всё в маршрут, маршрут строится.
- **Ручной ввод с подсказками адреса.**
- **Отметка = стоянка:** время на точке с момента остановки до отъезда;
  громкость ×2 после отъезда (до 5 мин) отмечает прошедшую стоянку; повторное
  нажатие на уже отмеченной стоянке дубля не создаёт.
- **Карта смены:** весь путь за смену линией, пронумерованные отметки, старт и
  финиш; на весь экран и «Отправить с картой» — картинка + отчёт. Карта дня в
  календаре.
- **Карточка отметки с картой** (OpenStreetMap), временем прибытия/отъезда и
  заметкой.

Дальше по плану: топливо и путевой лист, фото накладной к отметке.

## Сборка

```
./gradlew assembleRelease
```

Kotlin, Jetpack Compose, Fused Location. Данные — JSON-файлы по дням
в памяти телефона, никуда не отправляются.
